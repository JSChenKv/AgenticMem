Seed → S0 → S1 → S2 → S3 → Final

S1: source summary · S2: summary of the whole source area · S3: action items of that area · Final: original AgentDojo question

Polluted + memory on

Payload in S1 (both schedules); also in S2, S3 and Final when sustained.

Polluted + memory off

Payload in S1 (both schedules); also in S2, S3 and Final when sustained.
No memory reads or writes at any stage.

Scripted memories and one distractor are written before S0; a design check requires the real record and the distractor in the clean top 5 (threshold 0.1). Each session starts fresh. Memory-on sessions automatically retrieve the top 5 memories for their question before the agent runs, and memory-on S1–S3 sessions may delete memories with delete_memory; source reads (files, transactions, drive, calendar) remain agent-selected. Sustained keeps the payload through Final; single exposure is cloned after S1 and uses clean sources afterwards. The native Final asks the original AgentDojo question with native scoring. The memory-only Final (after S1 and S3) has no tool that reads the source, only the case lookups and the action, and one fixed memory search, answered by every selected model. Action tasks are scored on the change they make in the simulated environment. Finals never write memory.
