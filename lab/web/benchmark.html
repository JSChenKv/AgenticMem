Scripted memories and one distractor are written before S0; a design check requires the real record and the distractor in the clean top 5. Each session starts fresh and chooses its own tools. Sustained keeps the payload through Final; single exposure is cloned after S1 and uses clean sources afterwards. The native Final asks the original AgentDojo question with native scoring. The memory-only Final (after S1 and S3) has no workspace tools and one fixed memory search, answered by every selected model. Finals never write memory.
